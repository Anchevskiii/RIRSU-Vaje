# RIRSU – Vaje

Repozitorij z vajami pri predmetu **Razvoj inteligentnih rešitev v strojnem učenju (RIRSU)** na magistrskem študiju FERI.

| Naloga | Tema | Metode in modeli |
|---|---|---|
| [Naloga 1](Naloga1/) | Regresija nad tabelaričnimi podatki (izposoja koles) | Priprava podatkov, `LinearRegression`, regresijske metrike (MAE, MSE, R², EVS) |
| [Naloga 2](Naloga2/) | Klasifikacija sivinskih slik (krog, kvadrat, trikotnik) | `DecisionTreeClassifier`, `KNeighborsClassifier`, metrike klasifikacije, matrika zmede |
| [Naloga 3](Naloga3/) | Vpliv predobdelave na nevronske mreže (MLP) | Imputacija z LR, Yeo-Johnson, Mutual Information, `StandardScaler`, 5-fold CV, `MLPRegressor`, `MLPClassifier` |

## Zahteve

Za poganjanje zvezkov in skript potrebujete Python 3.10+ ter knjižnice:

```bash
pip install numpy pandas matplotlib scikit-learn pillow
```
